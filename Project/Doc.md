# CompanyGameV2 개발 문서 기준

이 문서는 전체 개발 플로우와 로드맵을 관리하는 기준 문서다.

## 기록 규칙
- 날짜별 실제 작업 내용은 `YYYYMMDD-내용.md` 형식의 별도 문서로 기록한다.
- 기존 날짜 문서는 덮어쓰지 않는다.
- 주요 구조나 로드맵이 변경되면 날짜별 문서에 변경 내용을 추가한다.
- 현재 확정된 전체 구조는 가장 최근 날짜 문서를 기준으로 확인한다.

## 현재 목표
**ChatGPT → GitHub → GitHub Actions → Cline → Unity**

자세한 현재 플로우와 로드맵은 날짜별 문서를 참고한다.
