# CompanyGameV2 개발 플로우 / 로드맵

## 2026-08-20

### 현재 확정 구조
```text
사용자
  ↓
ChatGPT
  ↓
GitHub
  ↓
GitHub Actions
  ↓
Cline CLI
  ↓
Unity
```

### 핵심 방향
- 기존 Agent/Bridge 구조는 폐기.
- 별도의 MCP, Telegram, Cloudflare Gateway는 사용하지 않는다.
- ChatGPT가 GitHub에 작업 명령을 등록한다.
- GitHub Actions가 명령을 감지하고 Cline CLI를 자동 실행한다.
- Cline이 Unity 프로젝트를 작업하고 자체 검증한다.
- 양방향 ChatGPT ↔ Cline 통신은 필수가 아니다.

### 안전장치
- 명령마다 고유 ID를 사용한다.
- 처리 완료된 명령은 다시 실행하지 않는다.
- GitHub Actions concurrency로 중복/동시 실행을 제한한다.
- 같은 명령이 GitHub에 남아 있어도 반복 실행되지 않도록 처리 상태를 관리한다.

### 다음 개발 순서
1. GitHub Actions + Cline 공식 GitHub 연동 구성
2. ChatGPT가 GitHub에 명령을 등록하는 방식 확정
3. 1회성 명령 ID / 처리 상태 구현
4. Cline 자동 실행 테스트
5. Unity 프로젝트 연결
6. 실제 Unity 작업 → Cline 자체 검증까지 전체 흐름 테스트
7. 안정화 후 CompanyGameV2 본 개발 진행

### 목표
**ChatGPT에서 명령 → GitHub에 등록 → Cline 자동 실행 → Unity 완성/검증**
